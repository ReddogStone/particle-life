# Particle Life

A small particle-life simulation. A few thousand coloured particles drift
around, and every type of particle attracts or repels every other type by a
random amount. From those simple rules alone, lifelike structure emerges —
cells, drifting worms, and swarms that chase and feed on one another. Every
world is generated from a seed (its **World Code**), so you can roll new ones,
copy the code, and share it for others to load the exact same world. On
Chrome/Edge you can also record a clip.
